# 第 7 组：新算子与不同表达泛化检验及编译器迭代（v2-7）

## 目标与规则

- **对照基准**：同设备上最好的成熟实现（cuBLAS/cuDNN、FlashAttention/TileGym、Inductor、Liger、ATen、oneDNN、GGML/llama.cpp、CNNL 等）；时间按完整调用的热执行中位数计。
- **分工（15 个新算子 + 3 个不同表达变体，共 18 个程序）**：
  - `gpu` 作者：`sliding_window_attention`、`alibi_attention`、`cross_entropy`、`topk_rows`、`qk_norm_rope` + 变体 `attention_unscaled_max`；负责出口：`triton`、`cutile`（5090D / H100）。
  - `cpu` 作者：`embedding_bag`、`index_add`、`triangular_solve`、`log_softmax_kl`、`retention_recurrence`、`radix_pass` + 变体 `layer_norm_welford`；负责出口：`mojo`、`weft`（x86 8 核）。
  - `dsa` 作者：`q6k_gemv`、`mxfp4_gemm`、`awq_int4_gemm`、`depthwise_conv2d` + 变体 `gemm_nt`；负责出口：`bangc`（MLU370）。
- **迭代纪律**：先记录开箱结果（泛化率），再仅通过通用编译器能力（legalize、变换、代价项、合同或微核）修复与优化，严禁按程序名或形状写特例；每次改动回归第 1–6 组。

## x86 有序 attention 复测（2026-11-26）

Xeon Platinum 8470Q，固定 0–7 核。每个出口在自己的 Bench 环境中使用相同输入、裁判和原生计时入口，交替测改前、改后和 ATen，取三轮中位数。表中时间为毫秒。两个 BF16 作者都声明了 `relaxed_normalization`；同语义列还从全局选项显式传入这项许可，并为点积开启 `denormal_fp_math="preserve-sign"`。

| 程序 | 出口 | 默认前 → 后 | 同语义前 → 后 | 同轮 ATen |
|---|---|---:|---:|---:|

| attention_unscaled_max | Weft | 186.98 → 171.25 | 186.08 → 95.52 | 26.62 |
| alibi_attention | Mojo | 223.75 → 168.49 | 225.45 → 39.69 | 45.09 |
| alibi_attention | Weft | 228.22 → 206.06 | 224.87 → 91.20 | 44.25 |

上表使用三轮交错复测的 `3ca525b` 与 `d41eba4`。最终同语义下，Mojo 的 unscaled 仍比本环境 ATen 慢 16%，ALiBi 的耗时低 12%。Weft 两项耗时分别为本环境 ATen 的 3.59 倍和 2.06 倍。

原有 1024 槽窗口在长行重算 QK；Mojo 分段计时中，重算和对应的 PV 消耗了 63%–67% 的工作线程周期。CPU 现在按共享输入、私有缓存容量和硬件收缩能力选择保留分数的范围、QK 与 PV 分块。Mojo 在整个调用中每个 V 平面只打包一次，并按有效键数执行 PV。两个出口都先求作者规定的峰值，再按作者的权重窄化类型完成第二趟归约。Weft 在线原型在这两项上分别为 154 和 149 ms。ATen 的 ALiBi 对照在调用前准备偏置；另测把广播偏置的构造计入完整调用约 35 ms。

FP16 滑窗的四个查询头共享 K/V；QK、权重、PV 分别占工作线程周期的 43%、13%、43%。在 32 个向量寄存器的设备上，CPU 为四行累加器选择 64 列 PV 分块。Mojo 完整调用从 265.30 降至 247.51 ms，同轮 ATen 滑窗 SDPA 为 614.96 ms。两种序列长度、五种运行期窗口的严格和作者语义共 20 个结果逐位一致。
