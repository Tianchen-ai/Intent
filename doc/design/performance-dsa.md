# DSA 供数的性能决定

| 原则 | supply 家族候选 | 分项 | 机器参数 | 验证 |
|---|---|---|---|---|
| 小搬运受每次提交开销限制；跨步搬运的每有效字节代价更高 | 单槽直供或双槽预取，按块／参与者划分 | 按输入、输出和复用分别计搬运字节、连续段数、传输次数 | 出口连续与跨步 DMA 带宽、每次 DMA 延迟 | softmax、转置 |
| 双缓冲在同一参与者有下一块时才能重叠 | 深度一与二，各自多个工作组 | 首块填充、末块排空及中间块 max(搬运,可重叠计算)；阻塞写回单计 | DMA 与计算吞吐、等待和同步延迟 | 短 softmax、长 RMSNorm |
| 核／簇利用由可分工作和每实例行数共同决定 | 每组行数与参与者数量组合 | 每核批次、尾波活跃率、每参与者可重叠的迭代数 | 可用核和簇、启动延迟 | 相同行宽的不同外域 |
| 多槽与临时量共享有限片上空间 | 有限完整行配置 | 对齐后的峰值 live bytes；超过可用容量属非法 | 物理容量、SDK 保留量、预算、对齐 | 大工作集 RMSNorm 与宽行 softmax |

模型使用当前 phase 的读写和依赖，区分可重叠的计算与必须先完成的同步。是否带来收益以相同输入上两份完整结构的独立测量判断。


## 阶段内复用

对于驻留遍历，只有方向为只读且不随行变化的输入才能跨行复用；存在可变输入时当前实现采用保守路径。供数决定同时携带槽数、参与者数量和是否保留不变量。DSA 在 schedule 的首个遍历之前形成 load_shared，验证其范围和对应读片段。BANG C 把它映射为每个实际参与者的一次片上搬运，随后所有行使用同一地址。双槽仍负责随行变化的数据。该优化的适用依据是访问关系，RMSNorm 的 gain 是其中一例。

参与者数由 `supply` 家族和设备容量决定。每个结构都发布合法的参数行，实际 winner 来自该结构的试跑。针对已验证的同形状 FP16 逐元素区域，DSA 计算整组输入和中间值所需的片上容量。BANG C 用成组 DMA 兑现满足步长、行边界和对齐条件的传输，对其他视图逐行兑现。供数模型分别记录首笔搬运、等待、排空和本地微核用时；指数与窄化商的常规路径按原生合成微基准估计，严格数值修正路径的额外耗时仍依赖数据。

## 元组归约

单通道的多个样本构成一个归约域。每组合并次数为行数乘以每行成员数减一，
以 `summary_merges_per_group` 记录。每次合并的八次浮点运算等价工作计入
计算时间，影响双缓冲可重叠的时间。读取独立通道的空间片段使用该视图的真实
维度和 stride，统计量按 owner 写回。训练 BatchNorm 同时验证输出和更新的状态。

## 多个归约和部分和

对需要把不同输入片段一起暂存的出口，完整驻留至少需要
`tile_width × 各独立输入片段每成员字节之和`。这个下界超过出口发布的单参与者
容量时，Block 只发布流式拓扑，并从能力表取可用的宽度。DSA 继续逐行检查
实际输入槽、临时量和 collective scratch 的总量。普通布局没有合法行时，
DSA 根据每个 SSA 片段的定义和最后一次使用计算临时槽，异步写的源保留到完成点。
BANG C 用同一份生命周期分析绑定地址。GroupNorm 的输入梯度检验这个容量边界；
LayerNorm 反向的 128 个 BF16 部分和检验流式行在完整调用中的绑定与完成。

同一参与者同时暂存多行时，驻留输入下界还要乘每实例行数。Block 为可用 pitched
DMA 读取的投影估算每个执行波次的提交开销；DSA 在供数选择前复用同一访问及其
逐点表达式，遇到写入或未知效果就失效。BANG C 按最快非 owner 轴的边界拆分
线性窗口，用实际 stride 区分连续段、广播和跨步访问。只有等长且 pitch 合法的
完整内段才合为一次二维 DMA；前缀和尾段仍处理实际有效元素。

## 前缀与间接读取

完整驻留行的 scan 用相邻前缀的分层相加，选择行组时考虑归约的计算量与每个有效片段的临时存储。间接读取在取数区显式形成 lookup_axis，分组传入索引再发起逐行 DMA；相邻逻辑行对应的物理行可以不相邻。按输入组的真实槽位数预算索引 scratch。
### 显式分段供数

二维连续特征可以在私有存储内按至多 16 个连续成员搬运，保留逐成员累加顺序。分配时计入行 pitch、片段字节和临时面板，最后一批按实际余量搬运。对互相独立的平坦输出，列 tile 可分别交给参与者；代价模型使用逻辑行组数与列 tile 数的乘积估算轮数。
