# CPU 任务与遍历的性能决定

| 适用原则 | partition 家族候选 | 分项 | 机器参数 | 验证 |
|---|---|---|---|---|
| 每个输出只属于一个任务。交换独立坐标能让内层沿目的地址连续前进 | 按源行、按目的行、二维 tile | 每个流的有效字节、内层 stride、触及缓存行数，读与写分计 | cache line 字节数，连续及跨步读写带宽 | 转置、普通逐元素 |
| 二维块的工作集能留在缓存时，相邻任务可复用读入的行 | 矩形 tile 与完整行 | 活跃输入和输出块的工作集，按行跨越的边界、重新加载量 | 数据缓存容量、带宽、写分配成本 | 原始与非整除转置 |
| 任务太短会让派发与 join 主导，过长会造成最后一波不均衡 | 不同 grain，尾块保留实际 extent | 批次数、最后一波的活跃 workers、派发和汇合时间 | affinity 下可用 workers、固定启动和同步延迟 | 小矩阵和宽矩阵 |
| 连续向量与间接 lane 的成本不同；不足一向量的尾段仍要计入 | 整行、向量面板 | 向量运算数、有效 lane 比例，结合内层 stride | 实际向量宽度与出口原生实现的吞吐 | 行归约、转置尾部 |

任务节点决定 ownership 和遍历。出口估计原生向量与供数成本，并兑现同一个任务合同。库调用的线程数遵循本机执行集合。


## 当前采用与模型误差

双射矩阵复制使用单独的 permutation 决策家族，普通独立计算、归约继续通过 partition。三个候选分别保持源行、交换工作区间两轴以连续写回、把目的矩形交给块内区间。它们共享 CPU 任务 ABI 与同步完成点。目的行是首轮在四个 CPU 执行组合中实测选出的产品配置，可派生切换。

首轮模型把矩形 tile 的局部性折算成了过高的跨步带宽收益。现有 tile 在块内仍会跨步写回。开发时分别检查预测的 time 和 explain 的 configuration override；配置选中值与模型纯排序可能不同。间接仿射 view 的物理 stride 从原实参和索引投影计算。
