# CPU 任务与遍历的性能决定

当多个独立 owner 通过相同商投影到同一个输入区间时，CPU 可以让它们在任务中相邻，按同一进度遍历该区间。模型估算每批 owner 的公共读取字节数。边界校验循环上下界、整组覆盖和只读循环体。Mojo 为每个 owner 保留私有累加器，整组共享经证明相等的加载，并可把多个 owner 的标量指数和窄化合成一次 SIMD 操作。

两次 fold 中的 query、key、坐标和缩放逐项相等，且期间没有写入时，CPU 在重复点积和 task 私有的 fp32 分数缓存之间选取。模型比较运算次数与缓存字节数。写缓存与按 token 重读的 SSA 值分别标明；Weft 在原生 task 中分配，Mojo 可对完整连续的查询小块共用 K/V 加载和向量指数。RVV 的向量结果乘标量再窄化写回时，可在最终发布处逐成员完成这三步以降低同时存活的寄存器组数。

| 适用原则 | partition 家族候选 | 分项 | 机器参数 | 验证 |
|---|---|---|---|---|

## 当前采用与模型误差

双射矩阵复制的 `permutation` 家族登记源行、目的行和二维 tile。默认配置仅登记策略和 realizer；三个候选由当前 CPU 模型按本次 shape、物理 stride 和执行集合排序。可在派生编译器中固定其中一项以比较生成结果。

tile 内层沿源行前进，块的边界缩短连续执行的跨度。对单个执行者，模型按内层跨度、物理步长和缓存组映射，从合成面板读写样本中插值单位字节时间。多个并发输出所有者使用相邻条带共享缓存行的合成样本。gather 和 scatter 的每个样本都包含一读一写。CPU 节点共用向量发射估算，向量宽度和实测吞吐来自目标。

Mojo 的矩形直接复制可兑现为完整的一维 copy sweep。其 verifier 核对两个二维视图、匹配的读写值及覆盖范围。一般逐元素计算继续使用向量 sweep 和尾段。Weft 和 Mojo 的 host 将同一执行者的连续 grain 合为一个原生区间，遇到投影视图的行边界时重新绑定地址。

## 元组状态与输出归属

通道归约把通道区间分给任务。并行任务可以独立写输出和 running state。

`members - 1` 次摘要合并，每次计八次浮点运算等价工作。当前吞吐项采用已校准

## 前缀与间接读取

扫描将整行交给同一任务，分块之间显式传递末项；计算代价包含每行的依赖加法。Mojo 在完整 SIMD 块与尾段之间延续同一 carry，Weft 在 native task 的 scf.for 中携带它。行查表索引沿 owner 轴，数据表共享，提交批次不能切走表头。Mojo 对独立连续行选择整行复制，非连续 view 沿实际 stride 读取。
### 偏移表与任务归属

按键发号可按输入区间或按计数器的缓存行分工。另一种候选先在任务私有表中统计各键的请求数，再对每个活跃键执行一次 relaxed fetch-add，返回的区间用于原有的 scatter。它要求独立的输入和目标、单位增量，以及返回值仅用于相同键的唯一目的地址。直接调用仍保持真实原子操作。模型在重复读取键的流量、共享缓存行的竞争、私有计数容量与每任务的预留次数之间选择。

按键归约由每个任务独占 partial 的 bin 行，扫描输入一次，随后由独立的作者调用按列合并。模型计入完整键流的实际字节。对于以布尔前缀作为唯一目的地址的 scatter，CPU 可以在任务中维持一个计数器，稳定写出选中位置后填充余下空间；每个任务的顺序依赖保留到最终计数。

分段的平坦输出可以按段号拆成任务，每个任务保留绝对 offsets 坐标，共享只读数据，独占一段输出。二维特征输出按外层段号分工，连续特征向量一次载入，非连续 stride 逐 lane 取值。代价计入压紧输入的成员读取量；成员次序决定严格累加的依赖链。

## 有序状态与分块收缩

成员独占输出时，任务按成员区间划分；carry 留在一个 task 内。模型比较可运行波数、并行成员数和分派成本。Mojo 消费 SIMD 状态，Weft 消费带成员维度的值和有符号索引谓词。维度为零时保留作者给定的初始状态。

chunk 内收缩复用输出矩阵块、host 调度和原生 panel。纯 RHS 映射若能分解成每个 K 的因子与每列元素相乘，可在准备阶段共享因子。保留 BF16 或在舍入后提前展宽到 FP32 是两个实现候选，选择时计入跨步转置、准备带宽与后续展宽次数。
